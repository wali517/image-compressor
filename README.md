# Image Compressor

Browser-based image compressor and converter (JPEG, PNG, WebP, GIF, SVG). All processing happens locally; no files are uploaded.

Next.js (App Router) + React 19 + TypeScript + Tailwind CSS.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
npm start        # run the production build
```
